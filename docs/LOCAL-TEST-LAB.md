# بيئة اختبار RojDeal المحلية — موافقة المستخدم لا تشمل الإنتاج

الحالة: سكربت تجهيز معزول جاهز؛ التشغيل الفعلي متعذر في بيئة المساعد لعدم وجود Docker/Podman أو Supabase CLI. هذا **ليس اختبار RLS ناجحاً** ولا إثبات أن سلسلة SQL ستطبق دون عائق على قاعدة فارغة.

تشغيل Supabase محلياً يحتاج CLI ومحرك حاويات متوافقاً مع Docker: https://supabase.com/docs/guides/local-development

داخل **مشروع الموقع الحالي** على الماك، بعد تثبيت Docker Desktop وتشغيله وSupabase CLI حسب وثائقه:

إذا كان test-lab/LOCAL-LAB.json موجوداً في النسخة الموحدة، تخطّ سطر prepare-local-lab: ملفات البنية مرفقة بالفعل. لا تحتاج إعادة رفع ZIP أو فك مصدر التطبيق مرة أخرى لتشغيل المختبر المرفق.

```bash
node scripts/prepare-local-lab.cjs "/المسار/إلى/RojDeal-App"
supabase start --workdir test-lab
node scripts/check-local-lab.cjs
```

ضع مكان المسار مجلد التطبيق المرجعي نفسه، وليس ZIP. لا تشغّل db push أو link أو أي reset على المشروع المنشور. لا يغير السكربت .env.local أو مصدر التطبيق. قاعدة المختبر ضمن test-lab وليست موقعاً إنتاجياً ثانياً.

الأداة تنسخ schema.sql ثم city_upgrade.sql ثم professional_admin_upgrade.sql قبل migrations التطبيق بالتسلسل، لأن أول migration يفترض وجود تلك الملفات. تضيف مقترح خيوط دعم الويب إلى **المختبر المحلي فقط**. لا تستبدل ملفاً مختلفاً في مختبر سابق؛ تتوقف أولاً. LOCAL-LAB.json يسجل البصمات.

الاستثناء المعلن الوحيد: ملف20260811002422_add_platform_owners.sql يضيف حسابات إنتاج ثابتة ولا يضيف بنية. لا يُطبّق في المختبر لكيلا يفشل FK أو يُنشئ نسخاً وهمية من حسابات المالك. أنشئ حسابات اختبار جديدة داخل المختبر؛ لا تستخدم حساب المالك المنشور كهدف حذف.

المنافذ المحلية: API54381، DB54382، Studio54383، البريد54384؛ الموقع المحلي3002. الفاحص يرفض عنواناً خارج loopback أو مشروعاً مرتبطاً عن بعد، ولا يطبع مفاتيح الدخول.

إذا فشل start في SQL أو تنزيل الحاويات، أرسل اسم migration ورسالة الخطأ فقط، لا كلمات المرور أو مفاتيح API. لا تبدّل إلى الإنتاج لتجاوز الخطأ. لم يُدّعَ اكتمال bootstrap أو اختبار OAuth/Storage/الأدوار حتى يعمل هذا المختبر فعلاً.

تنبيه: بيانات المواقع والنصوص القانونية التاريخية تأتي من المصدر كما هي؛ ليست بيانات عملاء حية، ولا اعتماداً قانونياً جديداً. لا يُفعل البريد أو الدفع أو النشر الخارجي.
