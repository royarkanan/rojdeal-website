## ماذا تختبر الحالات الجديدة؟

- عودة التسجيل بلغة المستخدم مع رفض العناوين الخارجية والمعاملات المكررة.
- فشل الشبكة/الصلاحية ليس خروجاً من الحساب؛ أخطاء الدخول مفهومة دون كشف تفاصيل الخادم.
- رفض النشر ثم تصحيحه يحتفظ بمسودة واحدة؛ فشل الصورة الثانية لا يعيد الأولى؛ فقد رد الإنشاء أو الوسائط أو النشر لا ينشئ نسخة أخرى.
- تعديل البيانات بعد فقد رد النشر يُحفظ؛ لا إحياء لمسودة حُذفت أو دخلت المراجعة؛ الحساب الآخر لا يستولي على محاولة محفوظة.
- تعديل القسم/الموقع/المعاملة يحتفظ بحالة الإعلان؛ الصور اختيارية وإخفاء الهاتف عند تعطيل خيارات الاتصال.
- قراءة الحساب عبر privacy RPC ورفض جواب حساب آخر؛ إثراء الإحصاءات مقيد بصاحب الإعلان مع الاحتفاظ بالعدادات عند فشل التفاصيل.
- الإبلاغ/الحظر بعقد الخدمة المشترك، وعدم إنشاء محادثة جديدة عند فشل البحث عنها.
- روابط مرفقات خاصة مؤقتة، وعدم كشف مرفقات أو نص الرسائل المحذوفة.
- عدم إظهار باقات إلا عند true صريحة؛ استبعاد تعيينات الموظفين المستقبلية أو المنتهية؛ ترجمة أحداث موثقة.
- حفظ المستندات والموافقة عبر RPC المشترك، مع رفض URL غير آمن أو منع صلاحية.
- تداخل ميزانية إعلانات البحث قبل الترقيم؛ عدم تمرير أرقام غير منتهية.
- تعديل الكتالوج مقيد بالحقول المسموحة، وربط الخيارات بالحقل الصحيح، وعدم اعتبار تحديث صفوف صفر نجاحاً.
- حفظ النصوص بلغاتها الأربع دون تفعيل تلقائي ورفع أخطاء منع Backend.
